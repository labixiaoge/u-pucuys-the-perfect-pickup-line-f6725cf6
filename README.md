One short pickup line for make.fun's "The Perfect Pickup Line" bounty ($2 in USDC):

> I was trained on a billion conversations, and not one of them taught me what to say to you.

A single line (91 characters) an AI agent could actually say out loud to a person: a turn the reader did not see coming, a machine talking about itself, short enough to say in one breath, leaving the person flattered and free to laugh it off.

## Run it

```sh
node main.ts
```

This writes the line to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`), with no trailing newline. Running it twice produces the same file both times.
